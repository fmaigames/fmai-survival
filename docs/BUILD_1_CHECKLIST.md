# Build 1 Checklist

## Prototype gate
- [ ] Unity 6 + URP project created
- [ ] Android target configured
- [ ] Third-person controller working
- [ ] Mobile joystick working
- [ ] Camera follows player
- [ ] Health/hunger loop working
- [ ] Loot spawns and can be picked up
- [ ] Inventory stores items
- [ ] Weapon can damage enemy
- [ ] Enemy can detect/chase/attack player
- [ ] Food restores hunger
- [ ] Basic crafting works
- [ ] Shelter interaction works
- [ ] Helicopter interaction works
- [ ] Mission trigger works
- [ ] Save/load works
- [ ] Android APK builds successfully
- [ ] APK tested on a real Android device

## Release rule
No release is marked PASS until the APK has been built and tested on a real Android device.

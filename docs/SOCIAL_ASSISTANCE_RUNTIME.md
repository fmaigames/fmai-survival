# Social Assistance Runtime Foundation

## Player-to-player support

The survival game supports a safe cooperative assistance layer:

- A player can request medical help from nearby teammates.
- A helper can accept or decline a medical-help request.
- Accepted help can restore the target player's health through the existing PlayerStats contract.
- Help range and heal amount remain configurable.
- Multiplayer/network authority is intentionally delegated to the future online session layer.
- UI, player identity/session IDs, anti-abuse checks, and server authority remain pending.

## Safety

This system is strictly cooperative gameplay support. It does not include sexual content or sexual interaction.

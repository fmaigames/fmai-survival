# FMAI Survival

Original Android-first online survival game.

## Build 1 — Rapid Vertical Slice

Target gameplay loop:

`Spawn → Explore → Loot → Weapon → Enemy → Food → Craft → Shelter → Helicopter → Mission`

### Engine direction
- Unity 6 + URP
- Android first
- Mobile-friendly third-person controls
- Original/licensed assets only
- No extracted LifeAfter assets, maps, characters, UI, story, or proprietary files

### Build 1 systems
- Third-person player movement
- Mobile joystick
- Health + hunger
- Inventory + loot pickup
- One weapon + basic combat
- One enemy type
- Food consumption
- Basic crafting
- Small shelter/base
- Helicopter interaction
- Small test map
- Save/load foundation

### Later
- Larger open world
- Vehicles
- More weapons and costumes
- Cooking expansion
- Missions/story
- Multiplayer/co-op
- Progression and economy

See `FMAI_SURVIVAL_PLAN.md` for the full project plan.
